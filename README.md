# Muhammad Rafi Portfolio

Single-page portfolio website ready for GitHub Pages.

## Run locally

Open `index.html` directly in your browser.

## Publish on GitHub Pages

1. Create a new GitHub repository (example: `muhammad-rafi-portfolio`).
2. Upload all files from this folder to the repository root.
3. Go to repository **Settings** -> **Pages**.
4. Under **Build and deployment**:
   - Source: `Deploy from a branch`
   - Branch: `main` and folder `/ (root)`
5. Click **Save**.
6. Wait 1-2 minutes. Your portfolio URL will appear in Pages settings.

## Image Naming

Project images live in `assets/images` with this 2-image structure:

- Image 1 (`pX_1.png`): project overview with one featured screen
- Image 2 (`pX_2.png`): three app screens in one image
